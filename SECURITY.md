# Security policy

## Supported version

Security fixes are applied to the current `main` branch and the production API deployment.

## Reporting a vulnerability

Use GitHub's **Security → Report a vulnerability** form for this repository. Please do not open a public issue for a suspected vulnerability.

Include the affected endpoint or component, reproduction steps, impact, and a minimal proof of concept. Do not include real receipt images, authentication tokens, API keys, or other people's personal data. We will acknowledge a complete report within three business days and coordinate disclosure after a fix is available.
